ClockHub Installer

Turns a Waveshare ESP32-S3 1.75" round AMOLED board into ClockHub: clock faces, internet radio, SD card music, news, weather, calendar and more. Works in Chrome or Edge on a computer.

New watch

Installs the app, its web page and every face in the gallery__FACES_NOTE__. Anything already on the board is erased.

This browser can't reach USB devices. Please use Chrome or Edge on a computer. USB access needs a secure (https) page.

Update a ClockHub watch

Installs the latest app but keeps the watch's Wi-Fi, settings and installed faces.

Use Chrome or Edge on a computer. USB access needs a secure (https) page.

How it works

  1. Put the board in install mode: unplug it, hold the BOOT button, plug it into this computer with a USB-C data cable, then let go. The screen stays dark; that's normal. Give Windows a few seconds to set it up.
  2. Click a button above and pick USB JTAG/serial debug unit in the pop-up.
  3. Wait while it installs (about 2 minutes for a new watch). Keep the cable plugged in.
  4. When it says the installation is complete, unplug the board and plug it back in normally. ClockHub starts.
  5. To set its Wi-Fi: click Install ClockHub again, pick the board (now shown as ClockHub or USB Serial Device) and choose Connect to Wi-Fi.

You can also update a watch that's already on Wi-Fi without a cable: open its web page, go to System and upload firmware.bin.

The watch only joins 2.4 GHz Wi-Fi. If a rotary knob is wired to it, set its pins on the watch's web page under Settings → Rotary knob.
